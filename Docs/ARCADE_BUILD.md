# UNI-MALY — Arcade & Build Notes

## Intended experience

UNI-MALY was made for a **two-player arcade cabinet**. It is a local-cooperative, 2D run-and-gun game designed around **two physical controllers**. Both characters share the same screen.

- **Players:** 2
- **Input:** gamepads for both players
- **Distribution:** Windows standalone
- **Public build:** [itch.io — UNI-MALY](https://alikb.itch.io/uni-maly)

## Running the downloadable version

1. Download the Windows archive from the itch.io project page.
2. Extract the entire archive rather than moving only the executable.
3. Connect two compatible gamepads.
4. Launch `GameStudio3.exe`.

The uploaded `UNI-MALY Build.rar` archive was inspected without running the executable. Its structure includes `GameStudio3.exe`, `UnityPlayer.dll`, `GameStudio3_Data/` and supporting Unity runtime folders, consistent with a Windows Unity build. The build may depend on controller drivers and the local Windows environment.

## Working with the source

This repository includes Unity project folders `Assets/`, `Packages/` and `ProjectSettings/`. It records **Unity Editor 6000.0.41f1** in `ProjectSettings/ProjectVersion.txt`.

Open the repository root in the matching Unity editor. No fresh import, build or hardware test was performed as part of the README/portfolio preparation. The archive on itch.io is the user-facing way to download the game.
